# Geolytica geocoding skills

When a task involves geocoding, reverse geocoding, address validation, postal codes, geoparsing locations out of text, or an address autocomplete field, read the matching skill before writing code:

- Canada or USA addresses, postal codes, ZIP+4, intersections, census geography: `skills/geocoder-ca-api/SKILL.md`
- Locations anywhere else in the world, or mixed/unknown countries: `skills/geocode-xyz-api/SKILL.md`
- An as-you-type Canadian address field in a web page: `skills/geocoder-ca-autocomplete/SKILL.md`

Load files under each skill's `references/` directory only when the task needs that language or that level of detail.
